# تقرير التعريب الاحترافي لـ WordCraft — RTL كامل

> **التاريخ:** 2026-11-04  
> **المشروع:** [storytold/wordcraft](https://github.com/storytold/wordcraft.git) — v0.15.1  
> **الهدف:** تحويل WordCraft إلى نسخة عربية احترافية مطابقة لـ Microsoft Word العربي، بواجهة معكوسة بالكامل (RTL) ومستندات تكتب من اليمين لليسار بشكل صحيح.

## 2) تحليل الوضع الحالي (Audit)

### 2.1 أين تعيش الترجمة؟
- الترجمات **ليست** في `wordcraft` نفسه، بل في المستودع المنفصل **[storytold/craft-i18n](https://github.com/storytold/craft-i18n)**:
  - `locales/ar/common.tsv` — 509 سطر (مشترك بين كل تطبيقات Craft)
  - `locales/ar/wordcraft.tsv` — 2,849 سطر (خاص بـ WordCraft)
  - `locales/ar/cadcraft.tsv` + `pdfcraft.tsv` للتطبيقات الأخرى
- `craft-i18n.rev = 9d6d54d` هو الذي يبني نسختك الحالية.
- كل سطر: `السياق <TAB> النص الإنجليزي <TAB> الترجمة العربية` — مثال:

```
	Home	الرئيسية
	Insert	إدراج
	Bold	غامق
```

- قاعدة: الترجمة تُكتب من المعنى فقط — **ممنوع نسخ ترجمة مايكروسوفت حرفياً** (قاعدة Clean-room في `AGENTS.md`).

### 2.2 نسبة الاكتمال
- `cargo xtask i18n-report` يفيد: **98% من النصوص المستخرجة مترجمة، ~93-95% من النصوص الظاهرة فعلياً**.
- ~14 نص جديد (Equation, Zotero, Read Aloud) ما زال إنجليزيًا في كل اللغات — ليس خاصاً بالعربية.
- المراجعة اللغوية: **لم تتم** بعد (السويدية والإيطالية فقط روجعتا من متحدث أصلي).

### 2.3 كيف يعمل الـ RTL في الكود؟

| الطبقة | الملف | ما يفعله |
|---|---|---|
| **واجهة egui** | `crates/ui-egui/src/rtl.rs` (393 سطر) | `root()`, `vertical()`, `horizontal_top()`, `far_side()`, `Table`, `island()`, `arrows()` — كل حاوية تُفتح من اليمين عند `Lang::rtl() == true` |
| **تحديد الاتجاه** | `crates/ui-egui/src/i18n.rs: RTL_LANGUAGES = ["ar"]` | `Lang::rtl()` يحدد الانعكاس، `direction::apply()` يضبط `Style::right_to_left` في egui |
| **النص ثنائي الاتجاه** | `crates/doc/src/bidi.rs` | `is_rtl_script()`, `has_rtl()`, `first_strong_is_rtl()` — يطبق UAX #9 قواعد P2/P3 |
| **التخطيط** | `crates/layout/src/para/lines.rs` + `bidi.rs` | يعكس الهوامش، المسافات البادئة، التفاف النص، Drop Cap عند `rtl_para=true` |
| **الحفظ/الفتح** | `crates/docx/src/read/props.rs` (`w:bidi`, `w:rtl`, `w:textDirection`) + `write/bidi.rs` | يقرأ ويكتب `w:bidi` للفقرة و `w:rtl` للمقاطع، ويقسّم المقاطع المختلطة حسب المستوى |
| **الخطوط** | `crates/fonts/src/ui_fallback.rs` + `word.rs` | اختيار خط عربي احتياطي + تشكيل عربي (lam-alef، ربط الحروف) عبر HarfRust |

> **الخلاصة التقنية:** الـ RTL ليس مجرد CSS — هو نظام طبقات كامل من egui حتى OOXML، وهو يعمل بالفعل. الوثيقة نفسها **لا تنعكس** ككل؛ كل فقرة لها اتجاهها — وهذا هو الصحيح مثل Word.

## 4) ما تم إصلاحه برمجياً في نسختك (Commits محلية)

### التصحيح 1 — `crates/ui-egui/src/i18n.rs`
```rust
// قبل:
LangInfo { code: "ar", prefer_hans: false, editing_lang: None },
// بعد:
LangInfo { code: "ar", prefer_hans: false, editing_lang: Some("ar-SA") },
```
**الأثر:** عند اختيار العربية في `ملف › خيارات › لغة الواجهة`، أي مستند جديد فارغ يكتب الآن `w:lang val="ar-SA"` و `w:bidi` تلقائياً عبر `Session::set_editing_language`. الكتابة تبدأ من اليمين.

### التصحيح 2 — `crates/fonts/src/ui_fallback.rs`
توسيع `arabic_candidates()` من 11 إلى 22 مرشحاً، بترتيب احترافي:
1. Noto Naskh Arabic (أفضل للواجهة)
2. Noto Sans Arabic
3. Amiri / Cairo / Tajawal / Scheherazade (خطوط مفتوحة احترافية)
4. DejaVu كاحتياط

**الأثر:** على Linux بدون Noto، سيجد الآن Amiri أو Cairo إذا كان المستخدم ثبّتهما — جودة أعلى بكثير.

> للتراجع: `git diff crates/ui-egui/src/i18n.rs crates/fonts/src/ui_fallback.rs`

## 6) دليل الـ RTL للمطور — كيف تتأكد أنه يعمل؟

### 6.1 تفعيل العربية فوراً
```bash
# 1) شغّل WordCraft بالعربية (بدون تغيير لغة النظام):
WORDCRAFT_LANGUAGE=ar cargo run -p wordcraft -- --sample

# 2) أو من داخل التطبيق:
# ملف › خيارات › لغة الواجهة › العربية › إعادة التشغيل

# 3) للتحقق من الانعكاس:
# - الشريط يجب أن يبدأ من اليمين: ملف | الصفحة الرئيسية | إدراج | ...
# - الألواح الجانبية (Navigation) على اليمين
# - مربعات الحوار: التسمية على اليمين والحقل على اليسار
```

### 6.2 كتابة مستند عربي RTL
```
1. مستند جديد (الآن ar-SA افتراضياً)
2. اكتب: "بسم الله الرحمن الرحيم"
3. يجب أن يبدأ المؤشر من اليمين
4. جرّب: الصفحة الرئيسية › فقرة › محاذاة إلى اليمين / توسيط / ضبط
5. جرّب فقرة مختلطة: "WordCraft يدعم العربية و English في نفس السطر 123"
   - يجب أن يرتبها محرك UAX #9 تلقائياً (العربية يمين، الإنجليزية يسار، الأرقام يسار)
```

### 6.3 فحص OOXML
```bash
wordcraft-cli inspect document.docx | jq .  # يجب أن ترى "bidi": true
unzip -p document.docx word/document.xml | grep -o 'w:bidi[^>]*'  # يجب أن تظهر
```
